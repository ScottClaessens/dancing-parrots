# Information on dataset `appendix2.xlsx`

**File name:** `appendix2.xlsx`

**Title:** Data on foraging group size and other variables for 350 parrot species from Beauchamp (2024)

**Authors:** Guy Beauchamp

**Reference:** Beauchamp, G. (2024). Parrots live in smaller groups on islands. *Biology Letters*, *20*(11), 20240413. <https://doi.org/10.1098/rsbl.2024.0413>

**Source data DOI:** <https://doi.org/10.5061/dryad.12jm63z75>

**Date accessed:** 18th August 2026

**Dimensions:** 350 rows x 22 columns

**Data dictionary:**

- `Species (phylogeny)` - Species name for linking to phylogeny
- `Old species name` - Alternative species name
- `Island living` - Island living (yes or no)
- `Min.group.size` - Minimum foraging group size (log scale)
- `Max.group.size` - Maximum foraging group size (log scale)
- `Geometric mean group size` - Geometric mean foraging group size (log scale)
- `Altitude.range (m)` - Altitude range in metres
- `Elevation (m = mountain; nm = non-mountain)` - Mountain living (nm: lowlands and m: restricted to mountains)
- `Conservation.status` - Conservation status according to IUCN
- `Body mass in log 10 scale` - Average body mass (log scale)
- `Habitat type (1 = closed; 2 = semi-open; 3 = open)` - Habitat type (1 = closed; 2 = semi-open; 3 = open)
- `Diet` - Diet (three classes: omnivore, granivore and frugivore)
- `Centroid.Latitude` - Latitude of centroid for breeding range
- `Centroid.Longitude` - Longitude of centroid for breeding range
- `Range.Size (square km)` - Range size (square km)
- `Population.Estimate (mid-point of mature individuals)` - Population size estimate
- `Population density (number per square km)` - Population density (number per square km)
- `Habitat use (% spent on the ground)` - Habitat use (% spent on the ground)
- `Research effort ` - Research effort (number of sources with available information on flock sizes)
- `TempRange` - Temperature range in celsius
- `AnnualPrecip` - Annual precipitation in mm
- `References` - References (sources with available information on flock sizes for that particular species excluding general texts)
